# Сайт компании медицинской диагностики «MedDiagCenter»

Экзаменационный проект веб-приложения на фреймворке **Django** с адаптивным интерфейсом на **Bootstrap 5**, полностью контейнеризированный с помощью **Docker** и **Docker-compose**.

## 🛠 Стек технологий
* **Backend:** Python 3.12, Django 5.x
* **Database:** PostgreSQL (Production / Docker), SQLite (Local Development)
* **Frontend:** Bootstrap 5, Django Crispy Forms
* **Зависимости:** Poetry (фиксация пакетов в `poetry.lock`)
* **Контейнеризация:** Docker, Docker-compose

## 📂 Структура проекта
* `config/` - Настройки и конфигурация Django-проекта.
* `core/` - Главная страница, раздел "О компании", "Контакты", формы обратной связи.
* `services/` - Каталог медицинских исследований, распределенный по категориям с ценами.
* `appointments/` - Кастомная модель пользователя, личный кабинет пациента, онлайн-запись на диагностику и просмотр результатов.
* `templates/` - Шаблонизация и HTML5/Bootstrap верстка страниц.
* `static/` - Локальные статические файлы Bootstrap (CSS/JS).

## 🚀 Запуск проекта через Docker-compose
Для развертывания проекта на локальной машине или на виртуальной машине Яндекс Клауд выполните команду в корневой директории:

```bash
docker-compose up --build
```
Контейнеры автоматически соберут образ приложения, запустят базу данных PostgreSQL, применят миграции и откроют проект на порту `http://127.0.0`.

## 🧪 Тестирование
Для проверки работоспособности кода и контроля покрытия (критерий >75%):
```bash
poetry run pytest --cov=.
```
